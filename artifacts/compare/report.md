## Reproducibility

Two consecutive unchanged runs both passed 184/184 frame checks and produced byte-identical `metrics.json`. PNG bytes are not a gate because the reference is live; use the metrics and generated composites for comparison.

## Remaining visual gaps

- The local index has 17 cards; the reference lists 90 components, so card inventory and sidebar depth differ.
- Sidebar groups, tab labels, brand and some copy are local rather than reference content.
- `home` is the docs shell, not the reference marketing page, and is intentionally not frame-gated.
- The component-detail template is absent locally; `detail-chat-composer` is captured for the reference only.
